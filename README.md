# Emoji Image Converter

[Open the live app](https://emoji.cong.ooo/)

Emoji Image Converter turns emoji into downloadable PNG and JPG image assets. Browse or search the emoji catalog, choose a platform style, adjust supported skin tones, and export clean emoji images for designs, profiles, posts, and messages.

The app supports Apple, Google, Microsoft Fluent, Twemoji/X, and OpenMoji/GitHub-style emoji sets.

## Features

- Browse and search emoji
- Export emoji as PNG or JPG
- Switch between platform emoji styles
- Choose supported skin tones
- Navigate emoji with grouped category browsing

## Tech Stack

- [Vite](https://vite.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Lucide](https://lucide.dev/) icons
- [emojibase](https://github.com/milesj/emojibase) emoji data
- Cloudflare/Wrangler static asset deployment

## Local Development

Install dependencies:

```sh
npm install
```

Start the development server:

```sh
npm run dev
```

Build for production:

```sh
npm run build
```

Preview the production build:

```sh
npm run preview
```
